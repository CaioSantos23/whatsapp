# Demonstração educativa de golpe virtual

Simulação baseada no material fornecido para apresentação de segurança digital. Abra `index.html` em um navegador.

O aviso de demonstração permanece no topo. Use um número fictício; a análise dura 20 segundos e pode ser concluída pelo botão de avanço. O botão final revela os sinais do golpe e permite reiniciar.

Nenhuma conta é acessada. Não há envio de números, rastreadores, APIs, vídeo externo ou pagamentos. Todos os resultados são fictícios. A política de conteúdo bloqueia conexões de rede.
